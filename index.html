Cadastro de Materiais

Além de caixas, o cadastro admite qualquer categoria de material (fitas, etiquetas, outros). O estoque mínimo e de segurança são definidos por SKU + Local, já que cada unidade (SP, RJ, PE, POA, BSB) pode ter uma necessidade diferente. Edições criam uma nova versão para aquele SKU+Local (histórico é preservado; a mais recente vale). Deixe um campo em branco se ainda não tiver o dado real — não preenchemos números fictícios.

Cobertura de Estoque (dias)

Cobertura = saldo atual ÷ consumo médio diário (últimos 30 dias). Calculada apenas quando já há histórico de consumo suficiente.

Ponto de Pedido

Ponto de pedido = (consumo médio diário × lead time) + estoque de segurança. Materiais em que o saldo já está no ponto de pedido ou abaixo dele precisam de reposição.

Previsão de Ruptura

Estimativa simples de data de ruptura = hoje + cobertura em dias, para materiais com consumo médio conhecido e maior que zero. Não é uma previsão estatística — é uma projeção linear do consumo médio recente.

Sugestão de Compra

Lista materiais no ponto de pedido ou abaixo dele. A quantidade sugerida é uma referência simples (estoque máximo − saldo atual, quando o máximo estiver cadastrado). O módulo de Compras (pedido formal ao fornecedor) ainda não existe neste sistema — a ação abaixo só sinaliza a intenção, sem criar pedido.

Importar Consumo via Excel (legado)

O arquivo deve ter colunas: DATA, LOCAL, CX P, CX M, CX G, CX GG (mesmo layout da planilha Google). Linhas com local não reconhecido são ignoradas e listadas abaixo. Nada é gravado até você confirmar a importação.

Importar Estoque (Snapshot)

Suba a planilha do estoque atual (colunas: DATA, LOCAL, SKU (ou CÓDIGO), ESTOQUE (ou SALDO)). O sistema compara com o snapshot anterior de cada Material + Local e calcula sozinho se foi consumo (saldo caiu) ou entrada (saldo subiu) — nada é lançado manualmente. Cada arquivo só pode ser processado uma vez. Nada é gravado até você confirmar.

E-mails para notificação de risco de ruptura

Todo dia, o sistema confere o estoque de cada caixa e envia um e-mail para os endereços abaixo sempre que o saldo estiver a 30% ou menos do estoque mínimo cadastrado (ou já abaixo dele). Cadastre aqui quem deve receber.
